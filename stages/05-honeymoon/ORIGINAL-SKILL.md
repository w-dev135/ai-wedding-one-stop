# Honeymoon Roadbook

专为新婚蜜月、结婚周年纪念及情侣深度度假打造的智能行程规划与交互式网页生成技能。核心设计理念是**以情绪价值与松弛感为第一优先级**，支持在 WorkBuddy、Claude Code、Trae、Cursor 等各类通用 AI Agent 环境中零配置运行，无需额外部署地图 API 密钥即可输出包含实时路线核实、情侣穿搭指南、全天候 Plan B 兜底方案及移动端一键导航的单页 HTML 路书。

## When to Use

* 用户计划蜜月旅行、新婚度假、结婚周年纪念旅行或情侣浪漫深度游
* 用户需要将目的地意向转化为结构化、慢节奏、高出片率的逐日定制方案
* 用户需要生成可在手机浏览器直接打开、带杂志级视觉设计与地图一键唤醒功能的 HTML 电子手册

## Steps

### Step 1: 浪漫需求对齐（轻量级温柔访谈）

若用户提供的初始信息不完整，使用温和、有期待感的语气收集核心偏好（单次最多追问 3-4 个核心问题，或直接提供默认推荐方案供用户微调）：

* **时空与大交通**：出发城市、意向目的地（国内/海岛/出境）、出行月份与总天数
* **当地漫游方式**：偏好双人自驾/租车、定制包车，还是高铁+打车漫游
* **度假基调与审美**：偏爱海岛躺平、雪山古镇慢生活、艺术人文探索，还是旷野景观巡礼
* **住宿与仪式感预算**：整体预算范围，以及对景观房型（私汤、悬崖海景、雪山露台）和特殊时刻（烛光晚餐、双人 SPA、旅拍）的期待

### Step 2: 松弛度与路线安全校验（蜜月黄金法则）

利用 Agent 内置的网页搜索能力核实各节点间的真实里程、交通耗时与季节性路况，并严格执行以下四项法则（详细标准见 `references/honeymoon-guidelines.md`）：

1. **防疲惫车程红线**：日均纯乘车/驾车时间严格控制在 **2.5 小时以内**（单日转场极限不超过 4 小时），拒绝特种兵式打卡。
2. **呼吸感留白机制**：每日最多规划 **1 个核心体验 + 1 个弹性漫步节点**，强制预留自然醒、午后景观咖啡或日落微醺的留白时段。
3. **低频换宿原则**：优先采用「2-3 晚连住」的换宿节奏，减少频繁整理行李对伴侣情绪的消耗；若涉及高海拔地区，必须遵循「阶梯式海拔爬升」原则（首晚住低海拔或全屋弥散式供氧房）。
4. **不走回头路动线**：优先设计异地进出港（开口程）或环线动线，规避折返跑与旺季拥堵黑洞。

### Step 3: 光影时刻（Golden Hour）与双人 OOTD 策划

结合出行月份的气候特征、日出日落时间与场景色彩美学，为每日行程注入高出片率指导：

* **黄金光线时刻表**：标出每日日出与日落蓝调时刻（Golden Hour & Blue Hour），指导最佳抵达机位的时间窗（如“17:45 抵达悬崖露台捕捉粉紫暮光”）。
* **双人色彩穿搭公式（OOTD）**：根据当日自然与人文背景色（如白族青瓦、藏地红墙、蔚蓝海岸、深秋红杉），提供同色系呼应或互补撞色的男女装搭配建议及材质提示（如三层洋葱式穿衣法）。

### Step 4: 逐日定制路书与双人预算精算

按天输出结构化浪漫行程，包含以下核心板块：

* **三段式慢节奏时间轴**：拆分为「晨间唤醒（自然醒/早午餐/晨雾漫步）」、「午后探索（核心景观/非遗手作/轻徒步）」、「日落与微醺（夕阳机位/仪式感晚宴/观星）」。
* **精选美宿与蜜月礼遇指南**：推荐兼具私密性与绝佳视野的设计师民宿或度假酒店，并附上**蜜月礼遇解锁话术**（指导用户凭结婚证或提前联络管家申请房型升级、欢迎甜品或天鹅鲜花布置）。
* **双人蜜月预算明细表**：使用 Markdown 表格清晰拆解往返大交通、当地包车/租车、景观美宿、浪漫餐饮、门票旅拍及机动备用金。

### Step 5: 晴雨双预案（Plan B）与行前备忘

为确保旅途情绪稳定，针对不确定因素提供周全预案：

* **阴雨天浪漫兜底（Plan B）**：凡涉及户外看山、出海、追日落的核心日期，必须同步提供 1 个高颜值室内替代方案（如独立美术馆、壁炉黑胶咖啡馆、双人非遗手作工坊或酒店私汤下午茶），确保坏天气不坏心情。
* **行前预约与健康清单**：列出需提前抢票的景区/餐厅预约节点、结婚证等证件提示，以及针对高原/海岛的常备护理包建议。

### Step 6: 输出移动端单页交互式 HTML 路书

在生成方案时，同步输出一个**零外部依赖、单文件自包含的 HTML 电子路书**（可直接写入本地 `.html` 文件，UI 规范与模板见 `assets/template.html`）：

* **杂志级浪漫视觉**：采用温暖柔和的高级配色（暖沙白背景 `#FAF7F2`、暮光玫瑰棕 `#C88A70`、深焦糖色 `#8C5843`），适配手机竖屏阅读与桌面端浏览。
* **核心交互组件**：
  * **顶部蜜月概览横幅**：展示旅行主标题、天数、日均车程、总预算与海拔/气候速查指标。
  * **按日切换标签栏（Day Tabs）**：支持点击平滑切换 `Day 1` 至 `Day N` 的详细时间轴、双人 OOTD 与阴雨天 Plan B 卡片。
  * **免 Key 地图一键唤醒**：内置通用地图搜索 URI 按钮（`https://uri.amap.com/search?keyword=城市+具体地点名称`），手机端点击即可直接拉起地图 App 导航，无需配置任何第三方 API Key。
  * **持久化行前清单（CheckList）**：底部内嵌支持点击勾选、一键重置并通过浏览器 `localStorage` 自动保存进度的行前准备清单。

## Gotchas

* **情绪价值高于景点数量**：当某景点顺路但会导致早起赶路或压缩休息时间时，主动将其裁剪或降级为“可选备选”，切勿塞满时间表。
* **杜绝编造经纬度**：在无地图 API 的通用 Agent 环境中，严禁捏造虚假的经纬度数值；统一使用准确的「城市+标准地名」构造通用搜索导航链接，保证导航 100% 可用。
* **完全独立纯净**：生成的路书文案与 HTML 代码仅服务于当前伴侣的旅行场景，不包含任何第三方署名、水印或外部私有服务依赖。
