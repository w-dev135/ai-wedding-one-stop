# 蜜月路书设计准则与美学规范 (Honeymoon Guidelines)

本文件定义了 `honeymoon-roadbook` 技能在规划行程与生成交互式网页时的核心检验标准。

---

## 一、蜜月防疲惫黄金参数表

| 维度 | 严格标准 | 设计原因 |
| :--- | :--- | :--- |
| **日均车程** | ≤ 2.5 小时（单日极限 ≤ 4 小时） | 长时间乘车极易引发烦躁与疲惫，超过 3 小时的转场必须在中间嵌入 1 个古镇/咖啡馆作为慢游中继站。 |
| **每日节点数** | 1 个核心体验 + 1 个弹性漫步点 | 留出充裕的双人互动、拍照与发呆时间，拒绝走马观花。 |
| **早起红线** | 原则上 09:00 后出发 | 蜜月旅行应保证自然醒；若需观赏日出或日照金山，优先选择「躺在房间露台即可直视景观」的酒店。 |
| **换宿节奏** | 2–3 晚连住换一次酒店 | 减少每天早出晚归收拾行李箱的琐碎消耗。 |
| **海拔梯度** | 首晚 ≤ 2,500m，逐级递升 | 涉及高原旅行时，遵循低海拔向高海拔过渡原则；抵达 3,000m 以上首晚严禁剧烈运动、饮酒与长时间热水泡澡，且必须指定全屋弥散式供氧酒店。 |

## 二、双人出片与色彩美学指南 (OOTD & Golden Hour)

1. **黄金光线时段（Golden Hour）**：
   * **晨光时刻**：日出后 30 分钟内，光线柔和金黄，适合雪山、古桥晨雾与海岸线。
   * **蓝调时刻（Blue Hour）**：日落前 30 分钟至日落后 20 分钟，天空呈现粉紫与深邃幽蓝渐变，最适合悬崖餐厅、海边露台与古城灯火人像。
2. **场景穿搭色彩公式**：
   * **苍山洱海 / 蔚蓝海岸**：米白、燕麦色亚麻长裙 + 浅卡其/白色亚麻衬衫（清爽呼吸感）。
   * **夯土古镇 / 秋日森林**：美拉德/大地色系（焦糖色风衣、麂皮夹克、灯芯绒与复古礼帽）。
   * **雪山冰川 / 蓝月湖泊**：高明度纯白羊绒大衣/毛衣 + 低饱和度克莱因蓝或浅灰配饰（自带反光板效果）。
   * **人文古建 / 红墙寺院**：新中式刺绣、暗红/黑金质感传统服饰，注意妆造干净自然。

## 三、晴雨双预案（Plan B）设计原则

每一天的户外核心行程必须配套一个**同区域、免奔波、高调性**的室内或半室内替代方案：

* **手作纪念类**：非遗扎染体验、手工打制银戒/铜器、唐卡描金、制香或陶艺工坊（既有互动感，又能带走专属新婚信物）。
* **松弛疗愈类**：景观酒店双人热石精油 SPA、私汤泡池下午茶、悬崖壁炉黑胶咖啡馆、独立书局/美术馆看展。

## 四、免配置地图导航链接规范

为确保在 WorkBuddy、Claude Code、Trae 等任意 Agent 环境中生成的 HTML 网页无需配置 API Key 即可一键唤醒手机地图导航，所有地点链接统一采用以下标准 URI 格式：

```text
https://uri.amap.com/search?keyword={城市名称}+{精准地点或景区名称}
```

* **正确示例**：`https://uri.amap.com/search?keyword=大理喜洲古镇`
* **避坑要点**：当某个著名景点默认导航会导流至高价收费骑马场或偏僻入口时（如香格里拉纳帕海），必须在按钮文字与 `keyword` 参数中直接替换为经过核实的免费精华路段名称（如 `keyword=香格里拉纳帕海哈木谷`）。
