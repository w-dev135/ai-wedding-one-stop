# 求婚定制向导

面向普通读者的求婚策划 Skill。跟着回答问题，获得现场方案、告白文案、视频分镜及可复制的生成提示词。由你自行生成素材、剪辑和执行现场安排。

## 快速开始
**支持 Skill 的工具**：将本仓库作为技能包安装，或按工具自身说明加载根目录 `SKILL.md`。启动时说：“使用 proposal-guided-wizard 帮我策划求婚，先了解她的偏好，再推荐风格。”安装位置和调用语法因工具而异。

**普通聊天工具**：打开 `通用对话启动版.md`，将全文上传或复制到新对话，接着说“开始引导我”。无需安装依赖。它包含所需规则，不依赖模型打开仓库链接。若工具限制文本长度，可上传文件；不能读文件时按章节分段发送，最后说“资料已齐，请开始”。

先选模式：完整求婚、只做视频、只做现场。每轮只处理当前需要的信息，也可一次填写 `assets/intake.md`。

## 风格
支持稳重真挚、创意叙事、惊喜反转、温柔治愈、轻松幽默、浪漫仪式。推荐一个主风格与一个辅助风格；视觉上可另选纪实、复古、古风或插画。

采集卡包含女方性格、年龄/年龄段、星座和审美。年龄与星座选填；星座只在对方喜欢时用于趣味表达，不用于推断人格或预测求婚结果。明确偏好优先于标签。反转采用温和揭晓，不用假分手、假事故等情感威胁。

## 能拿到什么
- 基于真实经历的主题方案、旁白和现场告白。
- 分镜、图片提示词、图生视频提示词、配音和音乐指引。
- 现场布置与动线、物料预算估算、人员分工、执行表和备用方案。
- 可复制进度摘要，方便换对话续做。

文字材料可以在没有媒体素材时交付，但标记为草案。预计时长需要读者生成配音后校准。没有回传图片/音频/视频，就不会声称已验收成片。

## 手把手搭建和发布
阅读 `搭建与GitHub发布教程.md`。先在常用工具试用，再分享给读者。无需填写 API 密钥，不需要付费接口；读者使用外部生成工具可能产生费用。

## 文件导航
- `SKILL.md`：入口和推进规则。
- `references/`：风格、写作、视频、现场的专项规则。
- `assets/`：采集卡、交付清单、进度摘要。
- `examples/`：虚构输入与风格示范，不是实际客户故事。
- `通用对话启动版.md`：普通聊天工具入口。
- `VALIDATION.md`：验证范围和实际限制。

## 兼容性
按标准 Markdown 技能结构组织；具体宿主的自动发现、文件读取和安装机制应实际核对。已完成本环境结构检查与文本试用，不代表所有模型或工具都已通过测试。通用对话版效果取决于模型的指令遵循能力和上下文容量。

## 真实资料
请把真实姓名、照片、详细地址、完整私人故事和生成媒体放在独立的私人项目中。本公开项目只含模板及虚构示例。分享输出前由你删除个人资料；上传照片前确认有权使用。

## V1.1：皮克斯风格3D动画分支
把已确认的大纲和分镜转成可执行动画制作包：分镜检查 → 角色定型 → 视觉定调 → 分镜图片 → 动态片段 → 剪辑衔接。
新增角色与时期参考、每镜完整提示词、生成长度/剪辑长度区分、变脸和动作失败的替代方案。真人动画化、原创角色及无照片表达均有入口；沿用已确认叙事风格。
启动示例：“我已有确认的大纲和分镜，请直接进入皮克斯风格3D动画制作分支，先检查分镜并指导角色定型。”
本功能提供文字材料与引导，不自动生成媒体，不承诺人物完全一致；用户自行操作生成工具。未回传图片时输出的是待适配草案。
