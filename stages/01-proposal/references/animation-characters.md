# 动画角色参考流程

## 选择人物来源
1. 真人照片动画化：读者自行提供有权使用的清晰正面与四分之三侧面照片，尽量光线均匀、无遮挡。没有侧面照可以从现有照开始，不把额外照片变成不必要门槛。
2. 原创角色：采集外形偏好，只承诺按设定创作，不声称像真人。
3. 不上传照片：可选原创角色或物件/背影表达，说明不能验证真人相似度。
照片只进私人制作项目，不进入公开技能源文件、示例或问题附件。

## 角色定型顺序
分别生成A、B的正面或四分之三侧面角色图，让用户选定；再以选定图为参考生成另一视角和全身图。避免先要求一张大图塞进所有视角，必要时分开生成。
接着测试双人同框，核对角色身份没有互换、身高与头身比例、画风是否协调。跨大学/现在等时期时，在同一角色基础上调整经确认的发型与服装，不重新捏脸。
记录：角色ID、时期ID、参考文件名、参考用途、选定版本、外形特征、衣服颜色与配件、相对身高、用户反馈。仅描述用户提供或实际可见的特征，缺失值标待确认。

## 角色提示词交付
每人提供完整提示词：上传参考图映射 → 人物身份与时期 → 保留特征 → 动画造型、材质、光色 → 景别与姿态 → 背景与比例 → 不变项与避免事项。
角色图建议中性背景、自然表情、清楚面部，避免遮脸道具。双人图明确图1对应A、图2对应B，并写站位与比例。
既无图也无外形描述时，先问人物来源，不擅自写黑长发、眼镜等设定。用户明确允许原创时可提出设定，但标为创意建议。

## 后续引用
逐镜列出要上传的已选角色图与场景图，说明哪张控制身份、哪张控制服装、哪张只供画风参考。参考图不存在时不得写成已选文件；草案使用明确的待准备项。
分镜提示词必须重述核心身份与视觉设定，不仅写“与上镜一致”。不要保证跨镜100%一致。当前工具看不了图时请用户按脸型、发型、服装和比例检查，记录“用户检查”，不宣称已视觉验收。
