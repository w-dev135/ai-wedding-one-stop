# 求婚信息采集卡
可以只填已知内容；不知道写“不确定”，不想填写可跳过。年龄、星座均选填，不需要生日、证件、手机号或精确地址。只需昵称。

## A. 这次要做什么
- 模式：完整求婚 / 只做视频 / 只做现场。
- 预计日期、还剩多少准备时间：
- 预算上限：；是否包含戒指、餐饮、场地：
- 场景：家中 / 包间 / 户外 / 其他；可用空间与人数：
- 参与者及能帮忙的事：
- 是否已交流过结婚意愿：已交流且积极 / 尚未交流 / 不确定（只用于安排表达方式，不预测结果）：

## B. 关于她（可改为伴侣的称呼）
- 昵称、你平时怎么称呼她：
- 年龄或年龄段（选填）：
- 星座（选填）：；她是否喜欢星座元素：喜欢 / 无感 / 不确定。
- 你观察到的性格：慢热、外向、细腻、理性、幽默、喜欢新鲜感、其他（可多选）：
- 一个能说明她偏好的真实小例子：
- 她更喜欢：两人独处 / 少量熟人 / 热闹聚会 / 不确定。
- 对公开求婚、被拍摄、被发到社交平台的接受度（分别填写）：
- 对惊喜/反转：喜欢 / 轻度可以 / 不喜欢 / 不确定。
- 审美：简约、复古、电影感、古风、童话、自然、其他：
- 喜欢的颜色、音乐、电影、共同爱好：
- 明确讨厌的安排、笑话、话题或画面：

## C. 两个人的故事
- 相识多久，怎样认识：
- 2—3件具体小事（发生了什么、地点类型、一个细节、为什么记得）：
- 共同拥有的物件或习惯：
- 有依据的原话（记不清就写大意，不用引号）：
- 为什么想和她结婚，用自己的话说：
- 你愿意承担的具体承诺：
- 不想出现在视频或现场的经历：

## D. 视频与制作条件（现场模式可跳过）
- 目标片长和屏幕比例；不知道可先写播放设备：
- 真人照片 / AI演绎 / 两者混合；已有素材数量与类型：
- 喜欢的整体风格，是否希望包含反转：
- 真人录音 / 合成配音 / 仅字幕：
- 准备使用的图片、视频、音乐和剪辑工具（可留空）：
- 结束后如何登场；是否有人控制播放：

## E. 风格偏好
稳重真挚 / 创意叙事 / 惊喜反转 / 温柔治愈 / 轻松幽默 / 浪漫仪式。
最多先选两个，也可以让助手根据B、C、D推荐。

## F. 动画制作分支（选择动画时才填写）
- 是否已有确认的大纲、旁白、分镜？提供当前版本即可：
- 视觉：皮克斯式温暖3D动画 / 其他；叙事风格仍沿用前面选择。
- 人物来源：真人照片动画化 / 原创角色 / 暂不提供照片。
- 已有角色图及选定版本；缺少时由向导带你制作：
- 需要区分的时期、发型、服装及重要辨识特点：
- 静态动态混剪 / 逐镜图生视频 / 不确定：
- 已有配音、工具和可接受试做预算（选填）：
不要求一次填完；已有资料直接沿用，年龄星座不决定角色长相。
