# 动画制作包模板
- 输入：已确认大纲/旁白/分镜版本、事实编号、目标时长、画幅。
- 叙事风格 / 动画视觉设定 / 动态制作方式：
- 角色A/B：人物来源、时期、外形特征、参考图映射、已选版本、确认依据。
- 分镜改写表：原镜号、难点、新镜号、表达变化、预计时长、确认状态。

每镜填写：
1. 镜号 / 所属时期 / 事实来源或创意演绎。
2. 参考图清单及各自用途（不存在的材料标待准备）。
3. 完整图片提示词。
4. 选定首帧及版本 / 实图是否已检查。
5. 完整视频提示词 / 目标生成长度 / 剪辑使用长度。
6. 预计时间轴 / 实测时间轴 / 对应旁白与字幕。
7. 不变项 / 动作检查点 / 失败替代。
8. 生成次数 / 已知花费 / 用户反馈 / 当前状态。

汇总：旁白与音乐材料、剪辑表、实际片长、待检查项、结尾静帧与现场衔接、进度摘要。
状态分别用：文字草案、用户已确认文字、等待素材、收到素材待检查、检查后待用户确认、用户已确认素材。不要自动补齐空白状态。
