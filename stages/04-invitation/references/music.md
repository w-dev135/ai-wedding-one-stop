# 配乐与特效配置

## 内置配乐来源

三首72秒演示音乐由本项目的原创音符序列、数学波形与包络合成产生，未引用外部录音、乐器采样或已有歌曲。制作脚本为 `scripts/compose_demo_music.py`，分发时直接携带已经生成的 MP3 即可。合成音色分别模拟拨弦与键盘、笛声与键盘、键盘与柔和持续音，适合验证网页声音体验。版本2调整三款节奏、音量层次、短反射及起止淡化，红白较轻快，花鸟较舒缓，鎏金保持庄重。正式产品的音乐品质可通过原创作曲或许可明确的曲目升级。

这三首演示配乐可以与本技能及生成的请柬一起使用、修改和分发。外部曲目必须单独保留使用及分发许可，不把网络音乐库的曲目默认当作可自由打包的素材。

## 配置项

| 字段 | 可选值 | 行为 |
| --- | --- | --- |
| bgm | auto / none / custom | 按风格使用内置配乐、关闭音乐、使用 music 指定的曲目 |
| music | 本地音频路径 | bgm=auto 时也可用该曲目覆盖内置配乐 |
| effects | off / subtle / normal / festive | 关闭氛围或选择少量、适量、较多粒子 |
| opening | true / false | 是否在进入时展示开帖封面 |
| particles | true / false | 是否使用花瓣、光点或开帖纸屑 |
| photo_transition | true / false | 是否给照片进入增加柔和动画 |

开帖按钮在同一次点击中调用音频播放，随后执行动画。播放失败时保留静音阅读和重试按钮。页面切后台后暂停音乐，返回时由用户重新点击播放。开场防重复触发，支持跳过和结尾重播。系统减少动态效果设置优先于特效强度。

将自定义音频处理为 MP3 时，可运行 `scripts/prepare_audio.py --input <音频> --output <mp3> --start 0 --seconds 72`。此可选处理步骤依赖 ffmpeg；基础生成器与已有内置音频不依赖 ffmpeg。不要将整段商业录音或需特别授权的音乐自动加入安装包。

## 版本2声音控制

music_volume 为0至1，默认0.55；宾客可在页尾调节。实际设备对音量控制的支持需真机验证。music_start 默认为0，music_seconds 默认为空；指定截取时自动调用本地 prepare_audio.py，依赖 ffmpeg 与 ffprobe。缺少工具或截取失败会停止重建，保留旧版。

music_credit 保存自定义曲目来源与用户已核对的使用范围，留在私有项目中。内置音乐仅是原创合成演示配乐，不宣称专业乐器录音。配乐选择由项目 music/bgm 管理；切换风格保留自定义音乐，auto 且无自定义路径时才使用该风格曲目。

重播会先暂停当前音乐，重新由有声或静音入口选择。评审页面切换风格销毁旧 iframe，避免两款声音重叠。页面后台暂停，回前台不自动续播。
