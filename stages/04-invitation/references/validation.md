# 验证与交付记录

每次只验证本次变化及具体剩余风险。保留证据层级，不把解析成功写成视觉验收。

| 验证层级 | 内容 | 合格证据 |
| --- | --- | --- |
| 配置与生成 | 必填、日期、照片数量、路径、错误输入保留旧版 | 实际脚本运行结果 |
| 项目修改 | 更换风格、时间、封面与恢复，未改字段保留 | 项目版本与输出对比 |
| 静态资源 | 入口、照片、配乐、元数据、发布资料边界 | check_publish 输出 |
| 交互逻辑 | 有声／静音、快速点击、跳过、后台暂停、重播、减少动画 | 事件检查或浏览器结果，注明方法 |
| 浏览器视觉 | 320、390、430px及桌面，长姓名地址、照片裁切 | 实际浏览器观察，工具不可用时待验证 |
| 平台宿主 | WorkBuddy、Claude Code、Codex、Gemini CLI 的安装、触发与执行 | 各平台真实运行记录 |
| 线上资源 | 真实地址返回当前入口与媒体 | 线上检查结果或部署回执，说明覆盖范围 |
| 分享海报 | 当前封面、时间与风格，中文缺字、文字溢出，演示标记 | 海报原图及缩略图实际观察；sharing.json 记录 |
| 二维码 | 海报1080、540、360px缩放后解码结果等于当前 public_url | 实际解码器运行；无解码器则待验证，不能替代微信长按实测 |
| 微信真机 | iOS/Android 微信、转发卡片、音乐与地图 | 真机测试记录 |

代表性输入：一张竖图、一张横图、横竖混合、12张图；无音乐、自定义音乐、错误音频、空资料演示；长姓名、长地址；修改后恢复；损坏照片重建失败后旧网页仍可访问。

减少动画时禁用动态粒子及进入动画，正文仍可见。没有 JavaScript 时正文和静态资料可阅读。图片警告要说明影响及处理办法。

交付文字采用实际状态，例如：“生成与资源检查完成；手机视觉、四平台运行、微信实机待验证。” 不写未执行的通过项。项目检查与测试素材不能加入安装包或宾客发布目录。

分享海报代表性场景：红白双喜竖图、花影横图、酒红金色；不同 cover_index、长姓名、三项时间；无 public_url 拒绝、旧配置线上报告拒绝、候选链接水印、字体缺字拒绝且旧海报保留。URL 程序检查、用户报告可访问、二维码解码、视觉及微信长按识别分别标注，保留证据范围。修改后检查海报 URL 与网页配置没有脱节。
